# Phase 8 Difficult Documents UI Reference

Phase 8 adds quality and uncertainty cues to the existing Structura UI language rather than introducing a new screen family. The deterministic Playwright baseline validates visual search mode, visual-result labeling, Viewer difficult-document banners, review-required trust cues, and the document-quality review task.

The committed Linux baseline is `tests/e2e/phase8.spec.ts-snapshots/phase8-difficult-documents-chromium-linux.png`. The mirrored reference image in this folder is regenerated from that same mocked browser test.
