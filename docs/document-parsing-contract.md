# Provider-neutral parsing foundation

This implements the initial X-01/X-03 adapter and artifact boundary under ADR 0009. It does not activate the production parser, replace existing relational structures, promote facts, or close G3.

`lib/document_parsing/structure.py` owns `structura.document_structure.v1`; its JSON Schema is under `contracts/parsing/`. The artifact contains an immutable original asset/hash, explicit run/generation UUIDs, complete ordered source-page inventory, original render identities, model invocations, ordered hierarchical elements, table/cell identities and spans, source-pixel locators and full searchable chunks. Every source page has an explicit processing state. Deferred/unsupported/failed pages may have no render; they never receive fabricated image hashes or content. IDs are assigned by Structura within one generation. A different generation produces different IDs.

`source_adapter.py` snapshots and verifies bounded immutable bytes, inventories all pages before model/page budgets, and renders one page at a time through PDFium or Pillow. PDF rotation, multipage TIFFs, source hashes, page and pixel limits are checked. Rendered PNGs are actual source pixels, with no decorative preview fallback. PDF-native text is separately attributed. This path imports neither Docling nor Torch.

`model_output.py` defines the smaller model-facing page schema. It has no storage UUIDs, canonical facts, native-source authority flags or acceptance controls. `qwen_page_parser.py` calls the accepted authenticated Oxcart profile with the source image and a bounded, explicitly labeled optional native-text hint. It requests original wording and complete reading-order/table content. The transport requires the configured served-model identity and schema-constrained final content; malformed/truncated/service responses remain operational errors. A valid schema does not establish transcription quality.

`normalization.py` assigns IDs, binds the response to its actual page image, converts the model's full-image 0–1000 coordinates to source pixels, and rejects impossible boxes, forward/cyclic parents, foreign pages, mismatched table ownership and overlapping/out-of-grid cells. These checks prove address and structure consistency. They do not prove that pixels support a quote or that the model omitted nothing. All model text/cells retain `model_transcription` origin, even when they repeat the supplied native text. Native text cannot be fabricated through this model output schema.

`searchable_text.py` retains all element and cell text in bounded chunks with page/element IDs and source origins. It does not turn transcription into accepted facts or change the existing search index. `document_parse.py` computes a candidate artifact and requires its caller to supply authority checks and immutable checkpoint storage. It checks authority before calls, before checkpoints and before returning. A page budget produces explicit deferred pages; resuming validates exact source renders, generation-owned IDs and raw-output hashes/structure before reusing checkpoints. Model failures preserve only previously completed checkpoints. These callbacks are an integration seam, not proof of durable database fencing.

Migration 094 adds truthful `qwen3_8_27b`/`pdf_native` source and neutral structural asset vocabulary. It does not rewrite historical Docling rows. The selected 27B source is recognized by model-review policy; no new model label may bypass that policy. The legacy `CanonicalParseResult`/Docling persistence path remains unchanged pending the immutable-generation migration and owning run service.

The synthetic probe `scripts/gpu/probe_native_parse.py --output-dir <new-directory>` checks two distinct source pages, general prose plus invoice content, typed structure, exact identifiers/amount strings and searchable projection through the real 27B adapter. It writes source, page images, raw outputs, normalized artifact and a clearly labeled synthetic smoke report. Its expected-string checks are not full recall/precision scoring or a holdout gate.

Remaining integration/acceptance includes durable desired-run and parse-generation storage, atomic activation and historical readers, verified source-to-evidence navigation, accepted-fact preservation, within-page continuation and long-document context/coverage evaluation, typed extraction/claim publication, generation-aware reindexing, cross-host embeddings and scored private-corpus fidelity/capacity. Production defaults cannot switch until those owning gates pass.
